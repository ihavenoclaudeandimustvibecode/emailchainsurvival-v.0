# MooDayZ v0.1
Top-down multiplayer survival (MooMoo x DayZ).

## Run locally
npm install && npm start  ->  http://localhost:3000

## Deploy on Render
1. Push this folder to GitHub.
2. Render -> New -> Web Service -> pick the repo.
3. Build command: `npm install`  |  Start command: `npm start`

Note: world state lives in memory and resets on restart. Free Render services sleep when idle.

## Controls
WASD move | Click swing | Q wall | R rotate wall | E eat/drink | Y inventory | Enter chat
